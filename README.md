# ILSIM 일심 쇼핑몰

압해도 홍무화과·청무화과와 게코사료를 소개하는 반응형 쇼핑몰입니다.

기존 운영 주소: https://ilsim-company.pages.dev

배포 경로는 **GitHub `korean-black-money/ILSIM-COMPANY` → Cloudflare Pages `ilsim-company`**입니다. `cloudflare/worker.js`를 빌드한 루트 `_worker.js`가 관리자·문의 API를 제공하고 기존 루트 HTML·이미지를 함께 제공합니다. Python 서버는 별도의 로컬 미리보기입니다.

Cloudflare 운영·미리보기 환경에 서로 다른 `DB` 저장소와 `ILSIM_ADMIN_HASH` 비밀값을 연결했습니다. 관리자 업로드 이미지는 D1에 분할 저장하며 별도 R2 활성화 없이 작동합니다. R2 `BUCKET`을 나중에 연결해도 기존 D1 이미지를 계속 조회합니다.

## 실행

Python 3.10 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
python3 server.py --port 8931
```

- 쇼핑몰: http://127.0.0.1:8931/
- 관리자: http://127.0.0.1:8931/#admin
- 최초 실행 시 관리자 아이디 `ilsim`과 무작위 비밀번호를 `.runtime/admin-access.txt`에 만듭니다. 이 파일은 로컬 소유자만 읽을 수 있고 웹으로 제공되지 않으며 Git에서도 제외됩니다.
- 초기 비밀번호를 직접 정하려면 최초 실행 전에 `ILSIM_ADMIN_PASSWORD` 환경변수에 12자 이상을 설정합니다. 이미 초기화한 데이터베이스의 비밀번호는 아래 명령으로 변경합니다.

```sh
python3 manage_admin.py
```

## 운영 방식

- **네이버 구매:** `https://smartstore.naver.com/pigisland`에서 주문·결제합니다. 사이트 장바구니를 네이버로 전송하는 연동은 없습니다. 구매자는 네이버에서 옵션과 수량을 다시 선택해야 합니다.
- **현재 판매 상태:** 2026-10-01 스토어 화면에 “판매중인 상품이 없습니다.”가 표시되어 무화과와 게코사료를 구매 상담 상태로 설정했습니다. 상품 관리에서 상태를 “판매 중”으로 바꾸고 상품별 주소를 등록하면 바로 구매 버튼이 표시됩니다.
- **구매 상담:** 사이트 내 상담은 결제나 주문 확정이 아닙니다. 서버가 최신 상품·옵션·가격을 확인한 뒤 저장합니다. 관리자의 “확정·완료 상담 금액”은 결제 매출이 아닙니다.
- **문의:** 사이트 서버에 저장되어 관리자 고객 문의 화면에서 확인합니다. 이메일·문자 자동 알림은 연결하지 않았습니다.
- **상품:** 상품 추가·수정·삭제, 옵션별 가격, 판매 상태, 이미지 업로드, 네이버 구매 링크를 지원합니다. 다른 방문자도 새로고침하면 저장 내용을 볼 수 있습니다.
- **게시물:** 작성·수정·공개·비공개·삭제, 댓글·댓글 비밀번호 삭제·좋아요를 지원합니다. 입력은 HTML로 실행하지 않고 일반 텍스트로 표시합니다.
- **통계:** 서버의 한국 시간 기준 일별 방문 세션 수입니다. Google Analytics 실시간 사용자·기기별 통계와는 다른 지표이며, 노출되어 있던 기존 분석 서버 비밀값은 제거했습니다.
- **개인정보:** 구매 상담·고객 문의는 90일 이후 삭제됩니다. 시작 시와 이후 API 요청 시 최대 1시간 주기로 정리합니다. 서버가 꺼져 있으면 다음 시작 시 삭제합니다. 댓글은 직접 삭제하거나 관리자에서 관련 게시물을 삭제할 수 있습니다.

## 자료 반영

- `data/catalog.json`: 최초 상품 설정. 홍무화과 500g/1kg/1.5kg/2kg은 제공 상세페이지의 16,000/24,000/31,000/37,000원, 청무화과는 18,000/27,000/35,000/42,000원을 반영했습니다. 현재 스토어 판매가를 검증할 수 없어 안내 가격임을 표시합니다.
- `images/red-fig/`, `images/green-fig/`: 사용자 제공 상세페이지 각 15장. 웹용 WebP 변환본과 대표 이미지입니다. 원본 폴더는 변경하지 않았습니다.
- `data/reviews.json`: `review_20261001_210117.xlsx`의 정상 전시 리뷰 15건. 홍무화과 13건, 청무화과 2건. 평균 평점은 각각 4.8과 4.0(소수 첫째 자리 반올림), 전체 4.7입니다. 낮은 평점도 모두 포함했습니다. 작성자 마스킹과 리뷰 문구를 유지하고 주문번호·고객 부가정보는 제외했습니다. 9건의 사진은 원본 네이버 이미지 주소로 연결하므로 원본 제공 상태에 따라 보이지 않을 수 있습니다.
- 기존 임의 작성된 후기·평점·이벤트 게시물과 검증되지 않은 자동구독 결제 기능은 실제 후기 및 이용 안내로 교체했습니다.
- 옛 `ilsim_*` 브라우저 데이터는 자동으로 옮기거나 삭제하지 않습니다. 과거 주문 데이터가 있다면 정합성 확인 후 별도 이전해야 합니다.
- JSON 초기 자료는 **새 데이터베이스 생성 시에만** 들어갑니다. 실행 후 상품 수정은 관리자 화면을 사용합니다.

## 기존 GitHub / Cloudflare 배포

현재 운영 사이트는 https://ilsim-company.pages.dev 입니다. 기존 `main` 푸시에 따른 자동 배포를 유지합니다. GitHub Pages나 Sites를 새 배포 대상으로 사용하지 않습니다.

현재 연결 설정과 재배포 절차입니다.

1. Pages 프로젝트 `ilsim-company`의 `DB`: 운영 `ilsim-company` (`e323816c-0514-47d4-afed-a66b9097d626`), 미리보기 `ilsim-company-preview` (`8e89185f-18c9-4da6-846e-7db29d9a7dd7`). 두 환경의 데이터를 분리합니다.
2. `cloudflare/migrations/`의 SQL을 해당 데이터베이스에 적용합니다. 이미 적용한 마이그레이션 파일은 수정하지 않습니다.
3. 업로드 이미지는 `image_chunks` 테이블에 512 KiB 이하의 Base64 조각으로 원자적으로 저장합니다. 파일 제한은 PNG/JPG/WebP 5MB입니다. 현재 계정에서 R2는 미활성 상태여서 사용하지 않습니다. 추후 `BUCKET`을 연결하면 새 업로드는 R2, 기존 파일은 D1에서 조회합니다. D1 무료 저장 용량은 데이터베이스당 500MB이므로 이미지 업로드가 많아지면 R2 전환을 권장합니다.
4. 관리자 비밀번호 검증값을 `ILSIM_ADMIN_HASH` 비밀 환경변수에 설정합니다. 형식은 `salt:PBKDF2-SHA256(100000회)`이며 비밀번호와 검증값을 저장소에 커밋하지 않습니다. `ILSIM_ORIGIN`은 지정하지 않으면 요청의 공개 Origin을 기준으로 검증하므로 운영·미리보기 주소에서 각각 작동합니다.
5. 빌드 후 `_worker.js`를 커밋하고 `main`에 푸시합니다. 기존 Pages 설정처럼 별도 빌드 명령 없이 루트를 배포할 수 있도록 완성된 `_worker.js`를 함께 관리합니다. `_routes.json`의 전체 경로 처리를 유지해야 소스·비공개 경로가 노출되지 않습니다.
6. Cloudflare 배포 성공 후 상품 조회·관리자 로그인·문의 저장·네이버 확인 파일을 공개 주소에서 검증합니다.

Node.js 24 환경에서 `pnpm install`, `pnpm build`, `pnpm test`로 서버 코드를 빌드하고 검증합니다. 스키마 변경 시에는 `pnpm db:generate`를 사용합니다. `data/`의 상품·게시물은 최초 데이터베이스 초기화 때만 들어가며 이후 수정은 관리자에서 수행합니다.

로컬 미리보기 데이터와 운영 서버 데이터는 자동 동기화되지 않습니다. 운영·미리보기 모두 관리자 비밀값을 설정하고 `fail_open=false`를 적용했습니다. `0000`·`0001` 마이그레이션을 두 저장소에 적용했으며 `d1_migrations`에서 적용 이력을 확인할 수 있습니다. 관리자 로그인 정보는 기존 로컬 `.runtime/admin-access.txt`와 같습니다.

## 검증

### 네이버 서치어드바이저 소유 확인

사용자가 제공한 `naveraa12cb19ff5b0b79be28136fa909732b.html`을 원문 그대로 웹사이트 루트에 추가했습니다. 전용 서버는 이 파일의 정확한 경로만 공개하며, 다른 비공개 파일은 계속 차단합니다.

`https://ilsim-company.pages.dev/naveraa12cb19ff5b0b79be28136fa909732b.html`에서 확인 문구가 표시되는지 확인하고, 같은 도메인으로 등록한 네이버 서치어드바이저 화면에서 소유 확인을 완료합니다. 로컬 미리보기 주소는 외부에서 접근할 수 없어 네이버 소유 확인에 사용할 수 없습니다. 소유 확인 파일을 기존 GitHub main에 반영했습니다. 네이버 계정 내 최종 소유 확인은 아직 완료하지 않았습니다.

```sh
python3 tests/test_server.py
```

별도 임시 데이터베이스와 로컬 테스트 서버로 인증·CSRF·비공개 파일 보호·상품 동기화·가격 검증·상담 중복 방지·취소 제외 집계·게시물 공개 설정·댓글 비밀번호·좋아요·문의 저장을 검증합니다. 실제 데이터는 건드리지 않습니다.
